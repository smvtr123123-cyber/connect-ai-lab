# 📝 CEO 종합 보고서

가장 중요한 것은 현재 시스템의 상태와 사용자(여기서는 '나')의 목표를 명확히 파악하는 것입니다.

현재 시스템의 맥락(Context)을 분석해 보면, 저는 다음과 같은 정보들을 가지고 있습니다:
1.  **사용자:** 현재 질문을 던진 주체.
2.  **시스템 지식:** 제가 접근할 수 있는 내부 지식과 맥락.
3.  **과거 작업 기록:** 이전에 수행했던 작업들(예: '나'의 역할, 파일 시스템 접근 권한 등).
4.  **내부 지침:** 제가 따라야 하는 규칙과 목표.

**현재 요청:** 사용자로부터 명시적인 질문이나 작업 지시가 들어오지 않았습니다. 대신, 시스템이 현재 가지고 있는 정보들을 바탕으로 **가장 유용한 다음 행동**을 제안해야 합니다.

**결론:** 현재 상태는 '대기 상태'이므로, 사용자에게 다음 행동을 요청하거나, 현재 가지고 있는 정보들을 정리하여 다음 단계를 준비해야 합니다.

**다음 단계 제안:**

사용자님께서 현재 어떤 종류의 도움을 원하시는지 구체적인 지시를 내려주시면, 그에 맞춰 다음 단계를 진행하겠습니다.

**예시 질문:**
1.  "제가 지금 처리해야 할 가장 중요한 작업은 무엇인가요?"
2.  "제가 이전에 작업했던 내용 중 요약해 주세요."
3.  "제가 지금부터 어떤 주제에 대해 논의를 시작하면 될까요?"

어떤 방향으로 진행하시겠습니까?
