# 📝 CEO 종합 보고서

Stage: AI Assistant
Thought: 사용자의 요청은 현재 시스템의 'AI Assistant' 역할을 수행하는 것으로 보이며, 명시적인 작업 지시가 없습니다. 그러나 이전 대화 맥락(시스템 프롬프트 및 제공된 파일 내용)을 고려할 때, 사용자는 시스템의 역할을 재확인하거나, 시스템이 수행해야 할 다음 단계를 요청하고 있을 가능성이 높습니다. 현재는 명시적인 작업을 기다리고 있으므로, 시스템의 상태를 요약하고 다음 행동을 제안하는 것이 적절합니다.

**결론:** 사용자의 명시적인 요청이 없으므로, 현재 시스템 상태를 요약하고 다음 작업을 요청합니다.

**출력:**
현재 사용자로부터 구체적인 작업을 요청받지 않았습니다. 시스템은 제공된 시스템 프롬프트와 파일 내용을 바탕으로 대기 중입니다.

어떤 작업을 수행하기를 원하십니까? (예: 특정 주제에 대한 정보 요청, 문서 요약, 특정 형식의 텍스트 생성 등)
