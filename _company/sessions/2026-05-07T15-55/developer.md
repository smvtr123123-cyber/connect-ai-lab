### 1. 데이터 소스 접근 권한 요구사항 (Data Source Access Requirements)

데이터 마이그레이션의 성공적인 실행을 위해, 목표 데이터셋에 대한 접근 권한을 다음과 같이 정의하고 요청합니다.

| 데이터 소스/시스템 | 필요한 접근 권한 | 접근 방법/인증 방식 | 비고 |
| :--- | :--- | :--- | :--- |
| **[부동산 데이터 DB]** (예: 기존 레거시 시스템) | `SELECT`, `INSERT`, `UPDATE` 권한 (전체 데이터셋) | DB 사용자 계정 및 연결 문자열 (또는 서비스 계정) | 마이그레이션 대상 핵심 데이터 |
| **[사용자 인증/정보 DB]** | `SELECT` 권한 (사용자 ID, 정보 등) | 별도 API 또는 서비스 계정 인증 | 사용자 데이터 마이그레이션 시 필요 |
| **[외부 데이터 API]** (예: 부동산 정보 연동 API) | API Key 및 인증 토큰 발급 권한 | 환경 변수 또는 시크릿 관리 시스템 | 외부 데이터 연동을 위한 설정 |

### 2. 개발 환경 설정 요구사항 (Development Environment Setup Requirements)

백엔드 개발 및 자동화 스크립트 실행을 위한 개발 환경 설정을 위해 다음 사항이 필요합니다.

*   **CI/CD 환경 설정:**
    *   GitHub Actions 또는 유사 CI/CD 파이프라인 설정 파일 접근 권한.
    *   개발 환경(Staging/Production)에 대한 배포 권한 및 환경 변수 설정 방법.
*   **코드 저장소 접근:**
    *   모든 백엔드 코드 및 스크립트가 저장된 Git 리포지토리(Repository)에 대한 읽기/쓰기 권한.
*   **개발 도구 설치:**
    *   필요한 언어 런타임, 데이터베이스 클라이언트, Docker 등 개발 환경에 필요한 필수 도구 설치 권한.
*   **보안 설정:**
    *   모든 민감 정보(API 키, DB 자격 증명)는 환경 변수(`.env` 파일)를 통해 주입하는 방식으로 설정되어야 하며, 직접 코드에 하드코딩하는 것을 금지합니다.
