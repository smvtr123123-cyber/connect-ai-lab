# 📝 CEO 종합 보고서

Stage-by-stage:

1.  **가장 중요한 목표 파악:** 현재 시스템의 목표는 주어진 모든 정보(문서, 지침, 이전 대화 기록)를 종합하여 **가장 가치 있고 실행 가능한 다음 단계**를 결정하는 것입니다.
2.  **정보 검토 및 분석:**
    *   사용자는 특정 지침이나 요청 없이 시스템의 **상태**와 **역할**을 제시했습니다.
    *   이전 대화 기록(Context)에는 복잡한 지침이나 구체적인 작업 요청이 포함되어 있지 않습니다.
    *   주어진 모든 정보는 시스템의 **메타 정보**와 **역할 정의**에 집중되어 있습니다.
3.  **결론 도출 (Action Plan):** 구체적인 작업 요청이 없으므로, 시스템은 **다음 상호작용을 위한 준비 상태**로 전환해야 합니다.

**실행 계획:**

현재 사용자에게 명확한 작업 요청이 없으므로, 시스템은 다음 단계로 넘어가기 위해 준비 상태를 확인하고, 사용자가 원하는 작업을 요청할 수 있도록 **준비된 상태**를 제시해야 합니다.

**결과:**

사용자의 요청이 명확하지 않으므로, 시스템은 **다음 지시를 기다리는 상태**를 유지하며 준비합니다.
