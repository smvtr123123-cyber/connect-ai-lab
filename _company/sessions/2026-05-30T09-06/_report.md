# 📝 CEO 종합 보고서

**[요약 및 계획]**

현재 시스템은 사용자 요청을 처리하기 위해 준비되어 있으며, 제공된 지침에 따라 가장 시급하고 중요한 작업을 식별하고 계획을 수립해야 합니다.

**현재 상황 분석:**

1.  **목표:** 제공된 모든 지침(특히 '사용자 요청 처리' 맥락과 '계획 수립')을 기반으로 다음 행동을 결정해야 합니다.
2.  **가용 정보:** 시스템은 현재 외부 입력(사용자 요청)을 기다리고 있으며, 내부적으로는 메모리에 저장된 복잡한 컨텍스트(다양한 파일, 지침, 메모)를 가지고 있습니다.
3.  **가장 시급한 행동:** 사용자의 다음 요청을 기다리거나, 만약 요청이 없다면, 시스템이 스스로 가장 논리적인 다음 단계를 제시해야 합니다.

**계획 수립:**

사용자가 명시적인 요청을 하지 않았으므로, 시스템은 현재 메모리에 저장된 지침의 맥락을 기반으로 **'다음 행동을 위한 준비 상태'**를 보고해야 합니다.

1.  **입력 대기:** 사용자의 구체적인 질문이나 요청을 기다립니다.
2.  **컨텍스트 확인:** 시스템이 내부적으로 접근 가능한 모든 지침과 메모를 다시 한번 확인하여, 어떤 종류의 작업(정보 검색, 문서 생성, 계획 실행 등)을 수행할 준비가 되었는지 확인합니다.
3.  **준비 완료 보고:** 준비가 완료되었음을 사용자에게 알립니다.

**결론:**

사용자의 다음 지시를 기다리며, 메모리 내의 복잡한 컨텍스트를 바탕으로 즉시 실행 가능한 상태로 대기합니다.
