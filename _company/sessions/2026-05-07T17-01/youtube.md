## 🎯 콘텐츠 기반 MVP 개발 로드맵 (Content-Driven MVP Roadmap)

이 로드맵은 **'콘텐츠 제작 $\rightarrow$ 시청자 피드백 $\rightarrow$ MVP 기능 정의 $\rightarrow$ 개발 및 검증'**의 순환 고리를 구축합니다.

### Phase 1: 신뢰 구축 및 니즈 검증 (Content & Validation)
**목표:** 시장의 핵심 Pain Point를 영상 데이터를 통해 정량적으로 확인하고, 앱 개발의 초기 스코프를 확정합니다.
**기간:** 2주 (10일)

| Step | 활동 내용 (Content Focus) | 주요 산출물 | 목표 연계 (Product Link) | 담당 에이전트 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 기획 및 촬영** | 최종 기획안 기반으로 **핵심 3개 영상** (후크 강한 제목/썸네일 적용) 촬영 및 편집 완료. | 3개 최종 영상 (최소 15분 분량) | - | ✍️ Writer, 🎨 Designer |
| **2. 데이터 수집** | 영상 업로드 후, **시청 지속률(Retention)** 및 **클릭률(CTR)** 데이터 집중 분석. | 영상별 상세 데이터 보고서 | **핵심 Pain Point 식별** (예: '지역별 가격 비교'에 대한 수요가 가장 높음) | 🎬 my\_videos\_check |
| **3. 후크 분석** | 댓글 및 시청자 반응 분석을 통해 **가장 많이 언급된 니즈**를 5가지 키워드로 추출. | 후크 키워드 리스트 (최대 5개) | **MVP 기능 우선순위 1순위 결정** | 💬 comment\_harvester |

### Phase 2: MVP 기능 정의 및 개발 준비 (Define & Prepare)
**목표:** Phase 1에서 확보한 데이터(Pain Point)를 기반으로, 개발팀이 가장 먼저 구현해야 할 **최소 기능 집합(MVP Scope)**을 확정합니다.
**기간:** 1주 (7일)

| Step | 활동 내용 (Strategy Focus) | 주요 산출물 | 목표 연계 (Product Link) | 담당 에이전트 |
| :--- | :--- | :--- | :--- | :--- |
| **4. MVP 스코프 확정** | Phase 1에서 도출된 **Top 3 Pain Point**를 해결하는 최소 기능 목록을 정의. (예: 단순 정보 제공 $\rightarrow$ 실시간 비교 기능) | MVP 기능 정의서 (Feature List) | **개발팀에게 전달할 명확한 요구사항** | 💰 Business |
| **5. 기술 요구사항 정의** | 정의된 MVP 기능에 필요한 데이터 소스(DB 구조)와 API 요구사항을 구체화. | 기술 요구사항 명세서 (DB Schema 초안) | **개발 환경 구축 준비** | 💻 Developer |
| **6. 데이터 접근 요청** | 개발팀에게 **KPI 기반의 데이터 접근 권한**을 공식 요청. (신뢰성 확보) | 공식 데이터 접근 요청 문서 | **개발 일정과의 연계성 확보** | 📱 영숙 |

### Phase 3: 개발 및 콘텐츠 순환 (Develop & Iterate)
**목표:** MVP를 개발하고, 이를 기반으로 콘텐츠를 제작하여 시장에 출시합니다.

---

### 실행 계획 (Action Plan)

1.  **Phase 1 실행 (1주차):**
    *   **실행:** Phase 1에서 언급된 모든 데이터를 수집하고, **MVP 기능 목록(최소 기능 집합)**을 확정합니다.
    *   **결과물:** MVP 기능 목록 및 기능 우선순위 문서.
2.  **Phase 2 실행 (2~4주차):**
    *   **실행:** MVP 개발 착수.
    *   **동시 진행:** MVP 개발 중, **'Coming Soon' 콘텐츠**를 기획하여 잠재 사용자에게 기대감을 조성합니다.
3.  **Phase 3 실행 (5주차 이후):**
    *   **실행:** MVP 출시 및 사용자 피드백 수집.
    *   **반복:** 피드백을 기반으로 다음 기능 개선 및 콘텐츠 전략을 재정비합니다.

**핵심 성공 요인:** 콘텐츠 제작(마케팅)과 제품 개발(MVP)을 **동시에, 그리고 ****상호 연결하여** 진행하는 것입니다. 콘텐츠는 제품의 마케터가 되고, 제품은 콘텐츠의 증거가 되어야 합니다.
