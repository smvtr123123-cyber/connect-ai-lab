# 📝 데이터 접근 권한 요청 문서 (개발팀 전달용)

**수신:** 개발팀
**발신:** SM Company (영숙)
**날짜:** 2026년 5월 8일 (가정)
**제목:** 부동산 추천 앱 MVP 개발을 위한 데이터 접근 권한 및 요구사항 요청

## 🎯 1. 프로젝트 개요 및 목표

본 문서는 부동산 추천 웹/앱 서비스의 MVP 개발을 위한 핵심 데이터 접근 권한 및 요구사항을 정의합니다. 목표는 **핵심 KPI 달성**에 필요한 최소한의 데이터 접근을 보장하여 개발 효율성과 보안을 극대화하는 것입니다.

*   **최종 목표:** 호갱노노와 같은 부동산 추천 안드로이드 앱 개발 및 서비스 출시.
*   **핵심 비즈니스 목표:** 구글플레이 앱 출시 및 구독자 1만명 달성.

## 📊 2. 데이터 범위 및 권한 요구사항 (Business & Developer 합의)

데이터 접근은 비즈니스 목표(KPI)와 기술적 제약 사항(보안)에 직접 연계되어야 합니다.

### 2.1. 필수 데이터 범위 (MVP Scope)
*   **핵심 데이터:** 지역 코드 기반의 매물 정보 및 부동산 관련 통계 데이터.
*   **제외 범위:** 비핵심 데이터 및 과도한 데이터 요청은 MVP 단계에서 제외하며, 데이터 요청 시 **'지역 코드'를 최우선 보안 필터**로 적용합니다.

### 2.2. 데이터 접근 권한 수준
*   **권한 요구사항:** 데이터 접근 권한은 **지역 코드 기반**으로 설계되어야 합니다. (DB 스키마는 지역 코드를 기준으로 설계됨)
*   **보안 요구사항:** 데이터 요청 시 최소한의 정보만 접근 가능하도록 권한 수준을 최소화하여 요청합니다.

개발팀은 다음의 기술적 요구사항을 기반으로 데이터 마이그레이션 및 API 설계를 진행해 주시기 바랍니다.

*   **DB 스키마 기반:** 이전에 논의된 DB 스키마 초안(sessions/2026-05-07T17-16/developer.md)을 기반으로 개발을 진행합니다.
*   **KPI 연계:** 핵심 KPI 달성을 위해 필요한 데이터 범위와 기술적 요구사항을 명확히 연결하여 개발 효율성을 극대화해야 합니다.
*   **실행 로드맵:** MVP 기능 우선순위와 DB 설계 완료 시점을 연계한 실행 로드맵을 준수하여 진행합니다.
