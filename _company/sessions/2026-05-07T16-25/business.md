## 📊 핵심 KPI 기반 데이터 범위 및 권한 수준 제안 (개발팀 논의 준비)

개발팀과의 논의를 위한 핵심 제안 프레임워크를 아래와 같이 제시합니다. 이 제안은 '수익화 모델 1개 가설 검증 및 매출화'라는 장기 목표에 직접적으로 연계되어, 기술적 요구사항을 비즈니스 목표에 기반하여 재정의하는 기반이 됩니다.

### 1. 핵심 KPI 정의 (KPI Alignment)

기술적 요구사항을 정의하기 전에, 개발팀이 달성해야 할 핵심 KPI를 명확히 정의하여 데이터 요청의 우선순위를 설정합니다.

| 비즈니스 목표 | 핵심 KPI (Metric) | 데이터 요구사항 (Data Dependency) | 측정 주기 |
| :--- | :--- | :--- | :--- |
| **수익화 가설 검증** | **활성 사용자 수 (MAU/DAU)** | 사용자 등록, 로그인, 세션 데이터 | 일/주 |
| **수익화 가설 검증** | **체류 시간 (Session Duration)** | 앱 내 핵심 기능(부동산 정보) 조회 및 탐색 데이터 | 세션 단위 |
| **수익화 가설 검증** | **핵심 행동 전환율 (Conversion Rate)** | 특정 부동산 정보 조회 후, 광고/서비스 연결 클릭률 | 일/주 |
| **서비스 품질** | **데이터 정확도 (Data Accuracy)** | 부동산 데이터의 최신성 및 정합성 (외부 소스 연계) | 실시간/일 |

### 2. 데이터 범위 및 권한 수준 제안 (Scope & Permission Level)

위 KPI 달성을 위해 요구되는 데이터의 최소 범위와 필요한 접근 권한 수준을 다음과 같이 제안합니다.

#### A. 필수 데이터 범위 (Minimum Viable Scope)

**목표:** MVP 기능(부동산 추천)의 핵심 가치를 측정하고 수익화 가설을 검증하는 데 필요한 데이터에 한정합니다.

1.  **사용자 행동 데이터 (User Behavior Data):**
    *   **포함:** 사용자 등록/로그인 정보, 앱 세션 기록, 핵심 추천 기능(부동산 목록, 상세 정보) 조회 기록.
    *   **제외:** 민감한 개인 식별 정보(PII)는 최소화하고, 행동 패턴 분석에 필요한 집계 데이터만 요청합니다.
2.  **부동산 데이터 연계 데이터 (Property Data Linkage):**
    *   **포함:** 추천 알고리즘 학습에 필요한 부동산 데이터의 **특정 필드** (예: 지역, 가격대, 면적, 거래 기록 요약).
    *   **제외:** 모든 상세 거래 기록이나 외부 데이터 소스에 대한 무제한 접근 권한은 MVP 단계에서는 제외합니다.

#### B. 권한 수준 제안 (Permission Level)

**목표:** 데이터 보안을 유지하면서 개발 속도를 확보하기 위해 최소 권한 원칙(Principle of Least Privilege)을 적용합니다.

1.  **데이터 접근 권한:**
    *   **제안:** **읽기 전용(Read-Only)** 접근 권한을 기본으로 설정합니다. 데이터 수정 권한은 특정 관리자 계정으로 제한합니다.
    *   **근거:** MVP 단계에서는 데이터의 무결성을 보장하는 것이 데이터의 양보다 중요합니다.
2.  **API 엔드포인트 접근 권한:**
    *   **제안:** 핵심 KPI 산출에 직접적으로 필요한 데이터만 조회할 수 있는 **특화된 API 엔드포인트**에 대한 접근 권한만 부여합니다. 전체 데이터베이스에 대한 접근은 별도의 보안 검토 후 진행합니다.
    *   **근거:** 데이터 요청의 효율성과 개발 일정 연계성을 극대화하기 위해 KPI 기반으로 논의를 진행합니다.

### 3. 기술 요구사항 재정의 준비 (Next Step Preparation)

위의 제안을 바탕으로, 개발팀에게 전달할 기술 요구사항은 다음과 같이 재정의될 준비를 합니다.

*   **기존 요구사항:** "부동산 추천 기능을 구현하라."
*   **재정의된 요구사항 (KPI 기반):** "사용자 행동 데이터를 기반으로, 특정 지역/가격대 부동산 목록을 제공하고, 사용자의 탐색 행동에 따라 추천 알고리즘의 정확도를 측정할 수 있는 최소한의 데이터 구조 및 API를 구현하라."
